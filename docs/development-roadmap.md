# 功能状态与后续规划

2026-10-20 对照当前主线实现核对。这里只列项目能力，不代表已经对所有部署环境完成验收。旧版规划原文见[历史归档](history/development-roadmap-20260621.md)。

## 已实现

| 能力 | 当前范围 |
| --- | --- |
| UID/昵称识别 | 明确 UID 标记或纯数字走资料接口；其他昵称走搜索；UID 清洗、严格分流、错误输入提示 |
| 拒绝反馈 | 原因、测得值/门槛、目标 UID、下一步；自定义补充、T/I 策略、完整原因同步 |
| 可独立导入的核心 | `src/gatekeeper/` 提供模型、条件、路由、格式化、解析、决策编排；插件负责 NoneBot 和外部适配 |
| T/F/I 分组管道 | 条件列表、all/any 汇总、命名跳转、阶段通知和告警；不支持布尔表达式 |
| 业务记录 SQLite | 审计、绑定、退群记录；旧 JSON 导入、WAL、事务、顺序升级 |
| 审批可靠性 | 请求去重、QQ/UID 身份锁、pending 先写、明确失败与未知结果区分、管理员人工确认 |
| QQ 等级回退 | `get_stranger_info` 与事件字段；均不可读时为 I，不能绕过协议端隐私隐藏 |
| Cookie | 手动设置、二维码登录引导、CookieCloud 可选同步、状态监控 |
| 日志与磁盘 | 仅本地按日保存、不自动清理；磁盘阈值私聊与可选邮件 |
| 启动脚本 | 安装缺失 uv、生成模板、首次询问 QQ/OneBot、快速模式跳过问答 |
| WebUI | 单审核文件的 YAML/表单编辑、分组增删与拖拽排序、goto 表单和流程预览、校验及原子保存 |

## 已移除或不支持

- **云端日志归档及上传后删除**：当前没有 WebDAV 自动归档，日志不会自动删除。
- **回复式人工审核新申请**：当前没有申请推送后回复 `y/n`、审核超时或默认人工审核策略。`/确认审批` 仅用于恢复结果不明确的已执行调用。
- **布尔条件表达式**：只支持 `conditions + mode`，不解析 `and/or` 或括号。
- **流程图拖线编辑**：WebUI 拖拽只改变分组排序，跳转目标通过表单编辑。
- **WebUI 多流程文件和群基础参数编辑**：当前仅支持一个实际流程 YAML，不编辑群基础 YAML。
- **二维码扫码自动回填 Cookie**：只生成登录链接/图片，Cookie 仍需手动设置或可选同步。
- **只填默认模板即可审核**：占位群默认关闭；快速启动不代填真实群参数或 Cookie。

## 后续工作边界

以下尚未实现，不能在安装说明中写成现有功能：

1. 独立于 NoneBot 的 OneBot 入口。目前只有业务核心独立，运行入口仍是 `bot.py`。
2. 版本化配置快照、变更历史及自动回退；现有原子文件替换不等于具备版本快照。
3. 将业务配置迁入 SQLite；当前仍遵循 [ADR 0001](adr/0001-sqlite-record-storage.md)，需单独设计迁移。
4. 审批 pending 按相关请求隔离；当前未知结果会暂停新的自动审批，不能凭成员查询自动重试。
5. 账号所有权挑战、成员巡检、额外请求频率控制与更复杂规则。

任何后续行为变更都需同时检查[当前规则](review-requirements.md)、[配置说明](configuration.md)、[拒绝反馈](rejection-feedback.md)、[交接文档](../AI_HANDOFF.md)和对应回归。
