**(F视为条件不通过,T视为条件通过,I视为忽略)**
# 筛选组A(拒绝组,依据顺序进行筛选,筛选出不满足条件的加群对象,任意一项为F视为不通过):
1. 是否退过群     (是 -> F , 否 -> T)
2. 能否搜索到b站账号     (无法搜索 -> F , 能搜索到 -> T)
3. 检查b站等级是否小于2级     (等级小于2级 -> F , 等级大于等于2级 -> T)
4. 能检索关注列表的,检索是否关注     (无法检索 -> I , 已关注目标主播 -> T , 未关注目标主播 -> F)
5. QQ等级是否能检索,并且是否小于4级     (无法检索 -> I , 等级小于4级 -> F , 等级大于等于4级 -> T)

根据结果决定下一步操作:
筛选结果 -> 所有项均为T / 任意一项为F / 任意一项为I,并且无F -> 通过 / 拒绝(根据F原因返回消息) / 进入筛选组B   

## 拒绝原因(仅拒绝F状态)
| 筛选结果 | 原因 |
| --- | --- |
| 无法搜索到b站账号 | 未搜索到你填写的B站账号 |
| 能检索关注列表,并且未关注目标主播 | 未关注主播,本群为主播粉丝群,禁止非粉丝加入 |
| b站等级小于2级 | 你的B站等级过低,疑似机器人账号 |
| QQ等级能检索,并且小于4级 | 你的Q等级过低,疑似机器人账号 |

**所有的拒绝原因前都会加上"来自BOT:"以告知对象这是来着BOT的消息,例如:"来自BOT:无法搜索到你填写的B站账号"**
**拒绝原因支持自定义**
